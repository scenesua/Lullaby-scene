# UI/UX 8단계: CSS 책임과 회귀 기준

기준: debug `755437d05bd5ceee25f4c0d18f2b565f9d249105` (1–7단계).
목적은 화면 재설계가 아니라 같은 화면을 만드는 중복 선언의 축소다.

## 파일 책임

| 약자 / 파일 | 책임 |
| --- | --- |
| B — `styles.css` | 기본 색상·표면·문자·선·그림자 토큰, 공통 레이아웃과 기본 컴포넌트. 테마 선택기가 없는 문서 페이지의 OS 테마 fallback 포함. |
| S — `site-shell.css` | 사이트 헤더·푸터, 랜딩/플레이어 외곽 컨테이너. |
| R — `site-runtime-v12.css` | 런타임 기능이 사용하는 공통 UI. |
| P — `polish-v9.css` | UI 폰트·보조 글자·포커스 토큰, 최종 데스크톱 밀도, 직접 시간 입력, 접근성, 소개/문의/법적 안내 페이지. |
| V — `player-v2.css` | 플레이어 패널, 여정 배경·장면 화면·이벤트 상태. 직접 시간 입력의 최종 스타일은 P 소유. |
| M — `mixer-controls-v14.css` | 믹서 개별 제어. |
| A — `mobile-android-shell-v1.css` | 모바일 앱형 셸, 상단 바 열 배치·작업 영역 여백·하단 탭, 모바일 조작. |
| D — `display-tools-v1.css` | 명시적 light/dark/system 팔레트의 최종 소유자, 암전 화면·버튼. 380px 암전 버튼 간격 보정 포함. |

## HTML의 실제 로드 순서

| 페이지 | 순서 |
| --- | --- |
| `/`, `/download/`, `/terms/` | B → S → P → R → M → A → D |
| `/player/` | B → V → S → P → R → M → A → D |
| `/about/`, `/contact/`, `/privacy/` | B → S → P |
| `/credits/` | B → S → P → R |
| `/blackout/` | R → M → A → D |
| `/404.html` | B → R → M → A → D |
| `/debug/` | 자체 스타일. 내장 플레이어는 `/player/` 순서를 따름. |

B의 fallback 색과 D의 명시적 테마 색은 일부 다르다. D를 B로 옮기면
소개/문의/개인정보 페이지의 색이 바뀌므로 통합하지 않는다. 반경·최대 너비는 B,
폰트·포커스·보조 글자는 P, 명시적 테마 팔레트는 D에서 관리한다.
새 토큰이나 파일 분할, 클래스 이름 변경은 추가하지 않는다.

## 정리 원칙

- 직접 시간 입력의 중복 정의는 P로 모으되 숫자 정렬과 모바일 버튼 최소 너비를 보존한다.
- 모바일 상단 바의 flex→grid 덮어쓰기는 A의 단일 정의로 합친다.
- 같은 요소의 데스크톱 열 너비/여백은 해당 데스크톱 미디어 쿼리에 둔다.
- `!important`는 충돌하는 중복을 없앤 규칙에서만 제거한다. 접근성,
  `[hidden]`, 암전·전체화면 및 실제 특이성 충돌이 있는 선언은 유지한다.
- 380/480/620/900/1180 등의 경계는 서로 목적이 다르므로 일괄 합치지 않는다.
- 동적으로 생성되는 이벤트·여정·믹서 클래스는 정적 HTML에서 안 보인다는 이유로 지우지 않는다.
- 오디오, JavaScript 동작, 서비스 워커, 광고·동의 정책은 변경하지 않는다.

## 검증

`web-css-refactor-smoke.mjs`는 동일한 현재 HTML/JS를 실행하되 비교 컨텍스트에서만
기준 커밋의 8개 CSS 응답을 제공한다. CSS 캐시 쿼리와 관계없이 파일명으로 비교한다.
별도 headless 브라우저 컨텍스트를 사용하고 Service Worker를 차단해 캐시 영향을 배제한다.

- 390/768/1024/1440px × light/dark/system(OS light/dark).
- 380/620/900/901/1180/1181px 경계.
- 여정, 설정, 믹서, 모바일 준비된 장면, 매크로 펼침, 데스크톱 배경 끔.
- 랜딩/소개/문의/개인정보/약관/출처/다운로드/암전/404의 OS light/dark.
- 실제 렌더링된 요소의 크기·색·배경·폰트·여백·테두리·그림자·배치 비교와 가로 넘침 검사.
- `CSS_ARTIFACT_DIR` 지정 시 대표 화면의 전후 캡처 저장.
- 장면 전체화면/회전/밝기, 재생, 키보드·터치 조작은 기존 UI/UX·여정 smoke로 별도 검증.

실행: 로컬 정적 서버를 켜고 `CHROME_PATH`, `WEB_BASE_URL`을 지정한 뒤
`node .github/scripts/web-css-refactor-smoke.mjs` 실행.
`CSS_BASE_REF`로 다른 기준을 지정할 수 있다. 얕은 체크아웃은 기준 커밋을 먼저 fetch한다.

공개 main 배포와 Android 빌드는 이번 정리 범위가 아니다. 검증 후 기존
`https://debug.lullabyscene.com/`에만 반영한다.
