# Lullaby Scene v1.1.0-alpha.3

This is a prerelease build for testing before the stable v1.1.0 release.

## Changes

- Makes the prerelease update channel visible in Settings.
- Keeps alpha, beta, and release-candidate builds opt-in.
- Improves the web Simple Scene quick mixer ordering and off-state behavior.
- Adds visitor count support for the web footer.
- Includes the latest aircraft-scene runtime and audio-processing fixes available on this branch.

## Important

This build is not the final stable v1.1.0 release. It may contain unfinished behavior and should be treated as a test build.
