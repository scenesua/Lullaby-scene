# Lullaby Scene v1.1.0-alpha.3

This is the previous prerelease build in the v1.1.0 alpha line. The active prerelease development target is now v1.1.0-alpha.4.

## Changes

- Makes the prerelease update channel visible in Settings.
- Keeps alpha, beta, and release-candidate builds opt-in.
- Improves the web Simple Scene quick mixer ordering and off-state behavior.
- Adds visitor count support for the web footer.
- Includes the aircraft-scene runtime and audio-processing fixes published with alpha.3.

## Important

This build is not the final stable v1.1.0 release. It remains available as the prior alpha for comparison and rollback testing.
