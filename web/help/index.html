재생 버튼을 눌러도 아무 소리가 없어요

기기 음량, 브라우저 탭 음소거, 플레이어 전체 음량, 개별 소스가 켜져 있는지 순서대로 확인하세요. 블루투스 기기로 출력되고 있는지도 확인합니다. 공유 링크는 자동으로 재생하지 않으므로 설정 미리보기에서 재생을 직접 시작해야 합니다. 처음 불러오는 소스는 네트워크에서 가져오는 시간이 필요할 수 있습니다.

화면을 잠그면 소리가 멈춰요

운영체제와 브라우저의 백그라운드 정책에 따라 다를 수 있습니다. 같은 장면이 화면을 켠 상태에서는 계속 재생되는지 먼저 비교하세요. 앱 사용 시에는 해당 앱의 배터리 제한 설정을 확인하고, 웹 사용 시에는 브라우저와 운영체제 버전을 함께 기록해 주세요. PWA 설치만으로 모든 기기의 백그라운드 제한이 없어지는 것은 아닙니다.

랜덤 이벤트가 안 나와요

여정의 랜덤 이벤트 토글이 켜져 있는지 확인하세요. 일부 이벤트는 특정 단계에서만 발생하고 간격도 무작위입니다. 여정을 시작한 직후나 짧게 듣는 동안에는 나오지 않을 수 있습니다. 단계 이름, 듣고 있던 시간, 이벤트 설정을 함께 알려주시면 단순 대기인지 재생 문제인지 구분하는 데 도움이 됩니다.

앱을 업데이트했는데 설치가 안 돼요

공식 다운로드 페이지에서 최신 GitHub 릴리스로 이동해 APK 다운로드가 끝났는지 확인하세요. 기존 앱과 새 APK의 서명이 다르면 덮어쓰기 설치가 거부될 수 있으며, 디버그 빌드와 정식 빌드를 오갈 때 특히 확인이 필요합니다. 바로 삭제하기보다 현재 버전과 새 파일명, 설치 오류 문구를 먼저 문의해 주세요. 앱을 삭제하면 앱 안의 설정을 잃을 수 있습니다.

업데이트 후 웹 화면이 예전 그대로예요

먼저 재생을 멈추고 페이지를 새로고침해 보세요. 같은 사이트를 여러 탭에서 열었다면 닫고 하나만 다시 열어 확인합니다. 그래도 문제가 남으면 플레이어 설정의 오디오 캐시 초기화를 고려할 수 있습니다. 브라우저의 ‘사이트 데이터 전체 삭제’는 캐시 초기화보다 범위가 넓고 저장한 프리셋과 환경설정도 지울 수 있습니다.

끊김이나 특정 소리가 거슬릴 때

같은 소스만 켜서 반복되는 위치가 일정한지 들어보세요. 항상 비슷한 시점이면 파일 내부나 루프 경계의 문제를, 여러 소스를 켰을 때만 발생하면 재생 부하나 겹침을 확인할 단서가 됩니다. 오류를 재현하기 위해 오래 불편한 소리를 들을 필요는 없습니다. 장면 이름, 소스 이름, 단계, 대략적인 경과 시간만으로도 조사에 도움이 됩니다.

문의할 때 보내주실 정보

scenesuastudio@gmail.com으로 기기 모델, 운영체제, 브라우저 또는 앱 버전, 문제의 장면과 재현 순서를 보내주세요. ‘재생 시작 → 3단계 이동 → 화면 잠금 → 소리 중단’처럼 동작 순서가 있으면 도움이 됩니다. 비밀번호, 인증 코드, 개인 계정 정보는 필요하지 않습니다. 공개 이슈가 부담스럽다면 이메일로 보내셔도 됩니다.

Playback and installation help

Start with checks that preserve your settings. Clearing browser data can remove saved presets, so use it only after simpler checks.

Nothing plays after I press play

Check device volume, tab mute, master volume and whether an individual source is enabled. Check whether output is being sent to a Bluetooth device. Shared links do not autoplay: start playback from the preview. A newly selected source may also need time to load from the network.

Playback stops when the screen locks

Background behavior depends on the operating system and browser. First compare the same scene with the screen awake. For the Android app, check its battery restrictions. For the website, note the browser and OS versions when reporting the issue. Installing the PWA does not remove every device's background restrictions.

I cannot hear random events

Check the journey's random-event switch. Some events are allowed only in particular stages, with randomized intervals. You may hear none immediately after starting or during a short session. Include the stage, listening duration and event setting in a report so we can distinguish scheduling from playback problems.

An Android update will not install

Use the download page to reach the official GitHub release and confirm the APK download completed. Android can reject an in-place update if the installed app and new APK have different signatures, particularly when switching between debug and release builds. Contact us with both versions and the error before uninstalling, as uninstalling can remove settings.

The website still looks like the old version

Stop playback and reload. If the site is open in several tabs, close them and reopen one. If the problem persists, consider the player's audio-cache reset. Deleting all site data in the browser is broader than clearing the cache and can remove presets and preferences.

A sound clicks or cuts out

Try that source on its own and note whether the interruption recurs at the same point. A consistent location suggests a recording or loop boundary; a problem that appears only with many sources suggests load or overlap. You do not need to keep listening to uncomfortable audio. Scene, source, stage and approximate elapsed time are useful clues.

What to include in a report

Email scenesuastudio@gmail.com with device model, OS, browser or app version, the scene and steps to reproduce. A sequence such as play, move to stage three, lock screen, audio stops is especially useful. Passwords, verification codes and personal account details are not needed. Email is available if you prefer not to post a public issue.
