현재 웹사이트가 처리하는 정보

Lullaby Scene 웹사이트는 현재 계정 가입, 광고, 분석 도구, 행동 추적 또는 자체 서버 기반 사용자 프로필을 사용하지 않습니다. 언어 선택은 브라우저의 localStorage에 저장될 수 있으며, PWA 오프라인 기능을 위해 정적 파일이 브라우저 캐시에 저장될 수 있습니다.

외부 서비스

Android 앱 다운로드나 소스 코드 확인을 위해 GitHub로 이동할 수 있습니다. 외부 사이트에서 처리되는 정보에는 해당 서비스의 개인정보 처리방침이 적용됩니다.

쿠키와 추적

현재 lullabyscene.com은 자체 광고 쿠키나 분석 쿠키를 설정하지 않습니다. 향후 광고, 분석 또는 계정 기능을 추가할 경우 실제 수집 항목과 목적에 맞춰 이 문서를 먼저 갱신합니다.

로컬 데이터 삭제

웹사이트가 저장한 언어 설정과 오프라인 캐시는 브라우저의 사이트 데이터 또는 저장공간 설정에서 삭제할 수 있습니다.

문의

개인정보 관련 문의는 Lullaby Scene GitHub 저장소의 공개 이슈를 통해 전달할 수 있습니다.

Privacy

Privacy Policy

Last updated: 2026-08-19

Information this website processes

Lullaby Scene currently does not use account registration, advertising, analytics tools, behavioral tracking, or server-side user profiles. Your language preference may be stored in localStorage, and static files may be cached by the browser for PWA offline functionality.

External services

You may be sent to GitHub to download the Android app or inspect source code. Information processed on external sites is governed by those services' own privacy policies.

Cookies and tracking

lullabyscene.com currently does not set its own advertising or analytics cookies. If advertising, analytics, or account features are added later, this policy will be updated first to reflect the data actually collected and its purpose.

Deleting local data

Language preferences and offline caches stored by the site can be removed through your browser's site-data or storage settings.

Contact

Privacy questions can be submitted through a public issue in the Lullaby Scene GitHub repository.
